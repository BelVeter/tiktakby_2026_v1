# Добавление кнопки создания заявки (kr_baza_new.php)

Кнопка "заявка" добавляется рядом с кнопкой "бронь" на странице `/bb/kr_baza_new.php`.
`model_id` уже известен из контекста строки таблицы — проблема выбора модели отсутствует.

## Proposed Changes

### [MODIFY] bb/kr_baza_new.php

1. **require_once** для `classes/Model.php` — нужен для `bron::createZayavka()`, который вызывает `Model::getById()`.

2. **AJAX-обработчик** `create_zayavka` — добавить в существующий AJAX-блок (`switch ($action)`).
   Принимает: `model_id`, `family`, `phone`, `validity` (дата), `info`.
   Вызывает `\bb\classes\bron::createZayavka()`, возвращает JSON.

3. **Кнопка "заявка"** — добавить в блок `$buttons` для статусов `to_rent` / `t_bron`
   рядом с кнопкой "бронь". Кнопка несёт `data-modelid` для JS.

4. **Bootstrap-модал** (`#zayavkaModal`) — добавить перед закрывающим `</body>`.
   Поля: Фамилия, Телефон, Срок действия до (date), Комментарий.
   Bootstrap 4 уже подключён на странице.

5. **JS** — добавить в конец: открытие модала с подстановкой `model_id`,
   AJAX-отправка, закрытие модала и алерт об успехе.

## Verification Plan

1. Открыть `/bb/kr_baza_new.php`.
2. Убедиться, что рядом с "бронь" появилась кнопка "заявка" для свободных товаров.
3. Нажать кнопку — должен открыться модал.
4. Заполнить форму и нажать "Создать заявку".
5. Модал закрывается, алерт "Заявка создана".
6. Проверить в `rent_orders.php` — запись с `type='zayavka'` и нужным `model_id`.
