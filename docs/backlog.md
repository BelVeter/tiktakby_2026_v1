## SEO-данные каталога (найдено 2026-07-23 при доработке `/pages/product`)

- [ ] **Пустой `<title>` на L3.** `resources/views/layouts/app.blade.php`: `<title>@yield('page-title')</title>` без фолбэка, у 18 моделей `rent_model_web.title` пустой → страница отдаёт `<title></title>`. На L2 фолбэк генерируется. Мелкая правка: дефолт вида «Прокат {name} в Минске».
- [ ] **`@yield('meta-description')` не экранируется** — кавычка или тег в поле ломают `<meta>`. Со стороны API это закрыто санитайзером в `PagesProductController`, но админка `bb/model_web.php` вырезает только кавычки, а L2-эндпоинт не чистит ничего. Полное решение — экранировать в шаблоне (сейчас в БД таких значений нет, двойного экранирования сущностей не будет).
- [ ] **6 групп дублей `page_addr`** в `rent_model_web` (одна из них — два разных `model_id`). API теперь отвечает 409, но данные надо развести в админке.
- [ ] **~117 моделей `status='show'` без канонического URL** — категория не привязана ни к одному `main_sub_razdel_id`. Страниц у них нет, в sitemap не попадают; кандидаты на `status='not_show'`.
- [ ] **26 групп моделей с одинаковым `item_name_main`** = дубли H1 на живых страницах. Поле теперь пишется через `PATCH /pages/product/{slug}` (`h1`), но правки видны и в печатных формах `bb/l_3_br.php` — проверять контекст.

## Мёртвая форма прямого заказа на L3 (найдено 2026-08-12)

Заказ с сайта оформляется только через корзину, но в карточке товара остался
целый путь заказа с тех пор, как корзины не было. Из интерфейса он недостижим —
проверять надо вызовы, а не наличие разметки:

- [ ] `resources/views/includes/l3_tovar_info_block.blade.php`: функция `l3CheckCartBeforeOrder()` объявлена, но **нигде не вызывается**, вместе с ней мертва модалка `cartWarningModal` («у вас есть товары в корзине — заказать только этот?»).
- [ ] Модалку `#orderModal` открывает единственная кнопка «Оставить заявку», и она рендерится только в ветке `@else` — когда товара **нет** в наличии. Поля доставки в форме скрыты атрибутом `data-show="whenfree"`.
- [ ] Следствие: ветка «есть свободный товар» в `L3Controller::l3Order2` (создание брони через `createBronStrong`) практически недостижима — попасть в неё можно лишь гонкой, когда товар освободился, пока клиент заполнял форму заявки, и тогда доставка всё равно не отмечена.
- [ ] Чистить эти три куска стоит одним заходом и только по явному запросу: форма может понадобиться, если прямой заказ решат вернуть.
