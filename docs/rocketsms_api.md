# Документация по интеграции с RocketSMS API

Сервис рассылок RocketSMS интегрирован в CRM сайта (директория `/bb/`) для отправки SMS-сообщений клиентам.

## Общие сведения
- Провайдер: [RocketSMS.by](https://rocketsms.by)
- Точка подключения: `api.rocketsms.by`
- Интеграция реализована через класс `\bb\classes\RocketSMS`.
- Учетные данные (УНП и пароль) загружаются автоматически из файла `.env` (ключи `ROCKETSMS_USERNAME` и `ROCKETSMS_PASSWORD`).

## Возможности API
На данный момент API сервиса предоставляет **только возможность отправки SMS-сообщений** (и получения их статуса). Функционал приема (входящих) SMS от абонентов не поддерживается данным API.
Отправка сообщений возможна на **номера любых стран** (в международном формате без знака "+"), при условии, что страна разрешена в настройках вашего личного кабинета RocketSMS.by.

## Класс `RocketSMS`

Файл: `bb/classes/RocketSMS.php`

### Инициализация
```php
require_once $_SERVER['DOCUMENT_ROOT'] . '/bb/classes/RocketSMS.php';

$rocketSms = new \bb\classes\RocketSMS();
```

### Отправка одиночного сообщения
Метод: `send($phone, $text, $sender = null)`
- `$phone` (string) — номер телефона в международном формате (например: `375296890043` или `79101234567`).
- `$text` (string) — текст сообщения в UTF-8.
- `$sender` (string|null) — имя отправителя. Если не указано, используется имя по умолчанию.

```php
$result = $rocketSms->send('375291234567', 'Ваш заказ оформлен!');
if (isset($result['id'])) {
    echo "Отправлено успешно. ID: " . $result['id'];
} else {
    echo "Ошибка: " . ($result['error'] ?? 'неизвестная ошибка');
}
```

### Массовая отправка
Метод: `bulkSend(array $phones, $text, $sender = null)`
- Позволяет отправить один и тот же текст сразу на несколько номеров.

### Проверка статуса сообщения
Метод: `status($id)`
- Возвращает статус сообщения по его ID (например: `QUEUED`, `SENT`, `DELIVERED`, `FAILED`).

### Проверка баланса
Метод: `balance()`
- Возвращает текущий баланс и количество доступных кредитов (SMS).

### Получение списка отправителей
Метод: `senders()`
- Возвращает массив зарегистрированных и одобренных альфа-номеров (Sender ID).

### Получение списка шаблонов
Метод: `templates()`
- Возвращает массив доступных шаблонов, если они были настроены в личном кабинете.
