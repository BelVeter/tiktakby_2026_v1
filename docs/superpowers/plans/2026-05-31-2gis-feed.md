# 2GIS YML Feed Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expose a daily-cached YML feed of rental services at `GET /feed/2gis`, listing 24 services with minimum weekly prices, for ingestion by 2GIS.

**Architecture:** A `Feed2GisController` generates the XML on demand (or serves from cache). A nightly Artisan command (`feed:generate-2gis`, scheduled at 03:00) pre-warms the cache. The `?refresh=1` query param forces regeneration. Each of the 14 service entries has a static filter descriptor (`sub_razdel`/`razdel`/`cat` URL key) that drives the DB price and photo queries.

**Tech Stack:** Laravel 8, PHP 7.4, `Illuminate\Support\Facades\DB`, `Illuminate\Support\Facades\Cache`, `Illuminate\Console\Command`

### 3a — Weekly Price Algorithm (critical section)

The algorithm replicates `TariffModel::getAmmountForDaysPeriod(7)` from `bb/classes/TariffModel.php`:

1. Fetch all tariff rows for the model.
2. Convert each to `[tier_days, daily_rate]` using `getDaysCalculatedNumber()`:
   - `step='day'`  → `tier_days = kol_vo`,      `daily_rate = rent_amount / kol_vo`
   - `step='week'` → `tier_days = 7 * kol_vo`,   `daily_rate = rent_amount / (7 * kol_vo)`
   - `step='month'`→ `tier_days = 30 * kol_vo`,  `daily_rate = rent_amount / (30 * kol_vo)`
3. Sort by `tier_days` ascending.
4. Initialize `$tarifPerDay` = daily_rate of the **first** (shortest) tier.
5. Iterate: if `7 >= tier_days`, set `$tarifPerDay = daily_rate` (longer applicable tiers are cheaper).
6. Return `round(7 * $tarifPerDay, 2)`.

This means:
- If a model has a 1-week tier (tier_days=7), it wins over the 1-day tier (since 7>=7 is true and the week rate is cheaper).
- If a model has only 2-week+ tiers (tier_days>7), the algo still runs but the loop never updates `$tarifPerDay`, so it stays at the shortest tier's rate — which is the 2-week daily rate × 7.
- A monthly-only model: tier_days=30, loop never fires, returns 7 × (monthly_rate/30).

    public function generate(Request $request): Response
    {
        if ($request->query('refresh') === '1') {
            Cache::forget(self::CACHE_KEY);
        }

        $xml = Cache::get(self::CACHE_KEY);

        if ($xml === null) {
            $xml = $this->buildFeed();
            // Cache until next 03:00 (or 24h if already past 03:00)
            $secondsUntilNextRun = $this->secondsUntilNextGeneration();
            Cache::put(self::CACHE_KEY, $xml, $secondsUntilNextRun);
        }

        return response($xml, 200, [
            'Content-Type'  => 'application/xml; charset=UTF-8',
            'Cache-Control' => 'public, max-age=3600',
        ]);
    }

    public function buildFeed(): string
    {
        $date = date('Y-m-d H:i');
        $lines = [];

        $lines[] = '<?xml version="1.0" encoding="UTF-8"?>';
        $lines[] = '<!DOCTYPE yml_catalog SYSTEM "shops.dtd">';
        $lines[] = '<yml_catalog date="' . $date . '">';
        $lines[] = '  <shop>';
        $lines[] = '    <name>TikTak — Прокат детских товаров</name>';
        $lines[] = '    <company>TikTak</company>';
        $lines[] = '    <url>https://tiktak.by</url>';
        $lines[] = '    <currencies>';
        $lines[] = '      <currency id="BYN" rate="1"/>';
        $lines[] = '    </currencies>';

        // Categories block
        $lines[] = '    <categories>';
        foreach (self::FEED_CATEGORIES as $catId => $catName) {
            $lines[] = '      <category id="' . $catId . '">' . htmlspecialchars($catName, ENT_XML1) . '</category>';
        }
        $lines[] = '    </categories>';

        // Offers block
        $lines[] = '    <offers>';
        foreach (self::SERVICES as $service) {
            $data = $this->queryServiceData($service['filter']);

            $price = $data['price'] !== null ? number_format($data['price'], 2, '.', '') : '0';
            $offerUrl  = self::BASE_URL . $service['url'];
            $photoLine = '';
            if (!empty($data['photo'])) {
                $photoUrl  = self::BASE_URL . $data['photo'];
                $photoLine = "\n      <picture>" . htmlspecialchars($photoUrl, ENT_XML1) . '</picture>';

    /**
     * Query DB for minimum weekly price and first photo for the given filter.
     *
     * Returns ['price' => float|null, 'photo' => string|null].
     */
    private function queryServiceData(array $filter): array
    {
        [$joinSql, $whereSql, $bindings] = $this->buildFilterClauses($filter);

        $tariffRows = DB::select("
            SELECT
                t.model_id,
                t.step,
                t.kol_vo,
                t.rent_amount,
                CASE
                    WHEN t.step = 'day'   THEN t.kol_vo
                    WHEN t.step = 'week'  THEN 7  * t.kol_vo
                    WHEN t.step = 'month' THEN 30 * t.kol_vo
                    ELSE 0
                END AS tier_days,
                CASE
                    WHEN t.step = 'day'   THEN t.rent_amount / NULLIF(t.kol_vo, 0)
                    WHEN t.step = 'week'  THEN t.rent_amount / NULLIF(7  * t.kol_vo, 0)
                    WHEN t.step = 'month' THEN t.rent_amount / NULLIF(30 * t.kol_vo, 0)
                    ELSE NULL
                END AS daily_rate
            FROM rent_tarif_act t
            JOIN tovar_rent tr ON tr.tovar_rent_id = t.model_id
            JOIN rent_model_web rmw ON rmw.model_id = tr.tovar_rent_id
                AND rmw.lang = 'ru' AND rmw.status = 'show'
            {$joinSql}
            WHERE {$whereSql}
              AND EXISTS (
                  SELECT 1 FROM tovar_rent_items tri
                  WHERE tri.model_id = tr.tovar_rent_id
              )
            ORDER BY t.model_id, tier_days ASC
        ", $bindings);

        if (empty($tariffRows)) {
            return ['price' => null, 'photo' => null];
        }

        // Group tariffs by model_id
        $byModel = [];
        foreach ($tariffRows as $row) {
            $byModel[$row->model_id][] = [
                'tier_days'  => (int)$row->tier_days,
                'daily_rate' => (float)$row->daily_rate,
            ];
        }

        // For each model, apply getAmmountForDaysPeriod(7) algorithm
        $minPrice = null;
        foreach ($byModel as $modelId => $tiers) {
            $price = $this->getPriceForWeek($tiers);
            if ($price !== null && ($minPrice === null || $price < $minPrice)) {
                $minPrice = $price;
            }
        }

        // Photo: first l2_pic from any active model in this filter
        $photoRows = DB::select("
            SELECT rmw.l2_pic
            FROM rent_model_web rmw
            JOIN tovar_rent tr ON tr.tovar_rent_id = rmw.model_id
            {$joinSql}
            WHERE {$whereSql}
              AND rmw.lang = 'ru' AND rmw.status = 'show'
              AND rmw.l2_pic IS NOT NULL AND rmw.l2_pic != ''
              AND EXISTS (
                  SELECT 1 FROM tovar_rent_items tri
                  WHERE tri.model_id = tr.tovar_rent_id
              )
            LIMIT 1
        ", $bindings);

        $photo = !empty($photoRows) ? $photoRows[0]->l2_pic : null;

        return ['price' => $minPrice, 'photo' => $photo];
    }

    /**
     * Build JOIN and WHERE clauses from the filter descriptor.
     *
     * Returns [joinSql, whereSql, bindings].
     */
    private function buildFilterClauses(array $filter): array
    {
        $type  = $filter['type'];
        $value = $filter['value'];

        if ($type === 'cat') {
            $join  = 'JOIN tovar_rent_cat trc ON trc.tovar_rent_cat_id = tr.tovar_rent_cat_id';
            $where = 'trc.cat_url_key = ?';
            return [$join, $where, [$value]];
        }

        if ($type === 'sub_razdel') {
            $join  = '
                JOIN tovar_rent_cat trc ON trc.tovar_rent_cat_id = tr.tovar_rent_cat_id
                JOIN sub_razdel sr ON sr.id_sub_razdel = trc.main_sub_razdel_id
            ';
            $where = 'sr.url_sub_razdel_name = ?';
            return [$join, $where, [$value]];
        }

        // type === 'razdel'
        $join  = '
            JOIN tovar_rent_cat trc ON trc.tovar_rent_cat_id = tr.tovar_rent_cat_id
            JOIN sub_razdel sr ON sr.id_sub_razdel = trc.main_sub_razdel_id
            JOIN razdel_subrazdel rs ON rs.id_sub_razdel = sr.id_sub_razdel
            JOIN razdel r ON r.id_razdel = rs.id_razdel
        ';
        $where = 'r.url_razdel_name = ?';
        return [$join, $where, [$value]];
    }

    /**
     * Replicate TariffModel::getAmmountForDaysPeriod(7).
     *
     * $tiers = [['tier_days' => int, 'daily_rate' => float], ...]
     * Already sorted by tier_days ASC.
     */
    private function getPriceForWeek(array $tiers): ?float
    {
        if (empty($tiers)) {
            return null;
        }

        // Remove tiers with zero daily_rate (safety guard for bad data)
        $tiers = array_values(array_filter($tiers, fn($t) => $t['tier_days'] > 0 && $t['daily_rate'] > 0));
        if (empty($tiers)) {
            return null;
        }

        // Algorithm mirrors bb/classes/TariffModel.php::getAmmountForDaysPeriod
        $tarifPerDay = $tiers[0]['daily_rate'];
        foreach ($tiers as $tier) {
            if (7 >= $tier['tier_days']) {
                $tarifPerDay = $tier['daily_rate'];
            }
        }

        return round(7 * $tarifPerDay, 2);
    }

    /**
     * Seconds until next 03:00 generation.
     * Ensures cache expires just before the nightly job, not sooner.
     */
    private function secondsUntilNextGeneration(): int
    {
        $now  = time();
        $next = mktime(3, 0, 0);
        if ($next <= $now) {
            $next = mktime(3, 0, 0, (int)date('n'), (int)date('j') + 1);
        }
        $seconds = $next - $now;
        return max(3600, $seconds); // at least 1 hour
    }
}

## Tariff Algorithm Reference

The `getPriceForWeek()` method in `Feed2GisController` mirrors `bb/classes/TariffModel.php::getAmmountForDaysPeriod(7)`. Key invariants:

| Scenario | Expected price |
|---|---|
| Model has 1-week tariff (7 BYN) + 1-day tariff (1.5 BYN/day) | 7.00 BYN (week tier wins: 7/7=1.0/day < 1.5/day) |
| Model has only 1-day tariff (1.5 BYN/day) | 10.50 BYN (1.5 × 7) |
| Model has only 2-week tariff (10 BYN total) | 5.00 BYN (10/14/day × 7, shortest tier used as baseline) |
| Model has only 1-month tariff (18 BYN) | 4.20 BYN (18/30/day × 7) |
| Category minimum = cheapest of all active models | correct — `$minPrice` is updated per-model |
