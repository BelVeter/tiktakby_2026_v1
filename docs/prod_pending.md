## Что НЕ требуется

**`npm run prod` не нужен** для этих веток. Весь новый фронтенд лежит в `bb/assets/`
(`live_picker.js`, `category_picker.css` и то, что добавится по производителям), а `bb/`
в сборку Laravel Mix не входит — `webpack.mix.js` его не упоминает, файлы отдаются как есть.
Правило «собрать и закоммитить `public/`» из `CLAUDE.md` действует только для фронтенда
самого сайта.

**Правка файлов на проде по SSH не требуется.** Всё уезжает через `Deploy.php`.
