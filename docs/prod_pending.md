# Что сделать на проде

Рабочий порядок: код пишется и проверяется **локально**, прод не трогаем. Этот файл —
накопитель действий, которые понадобятся на проде, когда владелец решит заливать.

**Как пользуется:** владелец говорит «залить ветку, дай ссылку на PR» → выдаётся список
из этого файла → выполняем совместно. Выполненные пункты **удаляются** из разделов
«перед/после заливки» и одной строкой переносятся в «Журнал» внизу.

## Что НЕ требуется

**`npm run prod` не нужен** для этих веток. Весь новый фронтенд лежит в `bb/assets/`
(`live_picker.js`, `category_picker.css` и то, что добавится по производителям), а `bb/`
в сборку Laravel Mix не входит — `webpack.mix.js` его не упоминает, файлы отдаются как есть.
Правило «собрать и закоммитить `public/`» из `CLAUDE.md` действует только для фронтенда
самого сайта.

**Правка файлов на проде по SSH не требуется.** Всё уезжает через `Deploy.php`.
